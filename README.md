# Life System Mod

Enhance your Minecraft experience with a life system that adds depth and strategy.

## Features

- Track player lives with a maximum of 4 lives
- Adjust player health to 10 when lives reach critical levels
- Team indicators for players with critical or maximum lives
- Command to give random lives to players

## Requirements

- Minecraft 1.21.11
- Fabric Loader 0.14.0 or later
- Fabric API

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/life-system-mod/releases).
2. Place the mod file in your `mods` folder.
3. Launch Minecraft with Fabric.

## Usage

### Commands

| Command | Description | Permission Level |
|---------|-------------|-------------------|
| `/randomlife` | Gives a random life to the player | 2 |
| `/randomlife @a` | Gives a random life to all players except operators | 2 |

### Permissions

- Players with permission level 2 can use the `/randomlife` command.

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the mod.
